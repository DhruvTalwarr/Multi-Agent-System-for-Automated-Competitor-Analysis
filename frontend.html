Every Layer of Intelligence

From real-time scraping to structured insight generation, each component is engineered for accuracy, relevance, and speed.

🔍

Live Web Intelligence

Automatically scrapes Google News RSS, strips boilerplate, and indexes fresh articles into a FAISS vector store in real-time per query.

📈

Financial API Integration

Smart ticker discovery via yfinance — fetches Market Cap, Revenue, P/E ratio, Debt-to-Equity, and 52-week high for any public company globally.

🧠

Hybrid-Search RAG

Combines FAISS semantic similarity (50%), BM25 lexical overlap (25%), source credibility (15%), and document recency (10%) for optimal retrieval.

🛡️

Critic Quality Gate

An independent AI critic inspects every generated report for hallucinations, missing companies, and formatting requirements. Rejects and re-runs if needed.

⚡

LangGraph Orchestration

Built on LangGraph state machines with conditional routing — the 4-agent pipeline loops intelligently until the report passes quality checks.

📊

Dual Report Modes

Architecture

The 4-Agent Pipeline

Each query flows through a stateful LangGraph orchestration, where agents collaborate and self-correct to produce enterprise-grade output.

01

🗺️ Planner Agent

Classifies query intent and domain (EV, smartphone, finance, startup). Generates 3–6 retrieval-optimized sub-queries to guide downstream research.

LLM · openai/gpt-oss-20b
02

🔬 Researcher Agent

Detects stale context and clears it. Triggers a live scrape via Google News RSS if no relevant data exists. Concurrently fetches real-time financial metrics via yfinance smart ticker discovery.

FAISS + yfinance + RSS Scraper
03

📝 Report Generator Agent

Selects a persona and synthesizes structured output — either a financial comparison table with markdown or a deep SWOT analysis with strategic recommendations.

LLM · openai/gpt-oss-120b
04

🛡️ Critic Agent (Quality Gate)

Validates report relevance by checking for requested company names, table presence in financial queries, and absence of hallucinated defaults. Loops back to Researcher if criteria fail (max 2 retries).

Rule-based + Keyword Matching
